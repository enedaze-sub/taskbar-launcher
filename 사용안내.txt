작업표시줄 런처 v4 — 나의 작은 다이얼

현재 사용 중인 런처에 업데이트를 적용했습니다.
기존 12개 등록 항목의 이름, 경로, 폴더 구조, 순서, 아이콘, 메모,
실행 인수와 작업 폴더를 업데이트 전후로 비교하여 그대로 보존했습니다.
전체 배경과 ‘실행 후 숨기기’ 설정도 유지했습니다.
기존 바탕화면 바로가기와 작업표시줄 고정 아이콘을 계속 사용할 수 있습니다.

1. 드래그로 표시 순서와 폴더 정리하기
• 설정창에서 카드를 누른 채 다른 카드의 왼쪽/오른쪽 가장자리로 끌면
  그 카드 앞/뒤로 이동합니다. 표시되는 선이 들어갈 위치를 알려줍니다.
• 폴더 카드의 가운데에 놓으면 폴더 안으로 들어갑니다.
• 다른 폴더 안의 카드 가장자리로 끌면 해당 폴더로 옮기면서 순서를 정합니다.
• 상위 경로, 왼쪽 라이브러리/폴더 목록, 뒤로 버튼으로 끌어 꺼낼 수도 있습니다.
• 부채꼴 런처에서도 각 칸의 가장자리는 순서 변경,
  폴더 칸의 가운데는 안으로 넣기, 아래 뒤로 버튼은 꺼내기입니다.
• 바뀐 순서는 자동 저장되며 설정창과 런처에 함께 반영됩니다.
  설정창을 닫으면 부채꼴이 최신 순서를 표시합니다.
• 자기 자신이나 하위 폴더 안으로 폴더를 옮기는 동작은 막습니다.
• 실제 파일을 이동하는 대신 런처의 등록 위치만 바뀝니다.

2. 휠로 다이얼 돌리기
• 부채꼴 위에서 휠을 아래로 돌리면 다음 항목,
  위로 돌리면 이전 항목으로 한 칸씩 회전합니다.
• 마지막 뒤에는 첫 항목, 첫 항목 앞에는 마지막 항목이 이어집니다.
• 이전/다음 페이지 버튼, PageUp / PageDown은 계속 사용할 수 있습니다.
  페이지 버튼으로 이동하면 해당 페이지의 시작 위치에서 표시합니다.
• 각 폴더는 마지막 페이지/다이얼 위치를 기억합니다.
• 테마 설정에서 한 번에 보일 칸 수를 5~9개로 조절합니다.

3. 폴더를 클릭하지 않고 펼치기
• 폴더에 마우스를 잠깐 올리면 옆에 내부 아이콘 메뉴가 나타납니다.
• 펼쳐진 메뉴의 아이콘을 바로 클릭하여 실행할 수 있습니다.
• 메뉴 안의 하위 폴더에 올리면 그 옆으로 다시 펼쳐집니다.
• 폴더와 메뉴 사이를 이동할 수 있도록 닫힘에 짧은 여유를 두었습니다.
• 폴더를 클릭해 기존처럼 부채꼴 내부로 들어갈 수도 있습니다.
• 메모가 있으면 중앙에 표시하며, 펼쳐진 메뉴에서도 설명을 확인할 수 있습니다.
• 폴더 메뉴도 항상 위 창이 아닙니다. 다른 앱을 선택하면 닫힙니다.

4. 6가지 테마와 나만의 커스텀 테마
• ⚙ → 설정창 위쪽 ‘꾸미기’ → ‘테마 / 색상 / 배치’로 엽니다.
• 민트 나이트: 어두운 민트색과 둥근 사각형 아이콘.
• 라벤더 문: 보라색 계열과 원형 아이콘.
• 딸기 밀크: 밝은 분홍색과 둥근 사각형 아이콘.
• 바닐라 라테: 밝은 베이지색, 미니멀 아이콘, 기본 6칸.
• 오션 블루: 파란색 계열과 원형 아이콘.
• 네온 오빗: 어두운 바탕과 라임 포인트, 미니멀 아이콘, 기본 8칸.
• 테마를 선택한 뒤 오른쪽에서 바탕/칸/포인트/글자 색을 바꿀 수 있습니다.
  색상 동그라미를 누르면 색상 선택창이 열립니다.
  #RRGGBB 색상 코드를 직접 입력해도 됩니다.
• 아이콘 모양, 칸 수, 아이콘 크기, 바깥쪽 위치, 칸 사이 간격,
  이름 표시, 중앙 메모 표시를 조절할 수 있습니다.
• 왼쪽의 실제 런처 미리보기에 변경 내용을 바로 반영합니다.
• ‘적용’을 누르면 선택을 저장합니다. ‘취소’하면 기존 테마를 유지합니다.
• 색상이나 배치를 수정하면 ‘내 커스텀 테마’로 저장합니다.
• 테마와 배치는 재실행 시 유지되고 라이브러리 백업에도 포함됩니다.

5. 전체 배경과 각 칸의 배경
• 전체: ⚙ → ‘꾸미기’ → ‘전체 배경 이미지’.
• 각 칸: 설정창 카드 또는 부채꼴 아이콘을 우클릭 → ‘이 칸의 배경 이미지’.
• 아이콘 이미지와 칸의 배경 이미지는 별도로 지정합니다.
• 이미지 선택 후 실제 부채꼴 미리보기에서 드래그로 위치를 맞춥니다.
  휠 또는 슬라이더로 확대하고 가로/세로 위치, 어둡게 정도를 조절합니다.
• 칸별 배경은 해당 칸에만 잘라 표시하며 다른 칸과 전체 배경을 유지합니다.
• 선택한 각 이미지마다 확대와 위치를 따로 저장합니다.
• ‘기본 배경’ → 적용하면 해당 이미지 설정만 해제합니다.
• 배경에 빈 공간이 생기지 않게 채우므로 이동하려면 먼저 확대하세요.
• PNG / JPG / JPEG / BMP / GIF를 지원합니다. GIF는 정지 이미지로 표시됩니다.
• 선택한 이미지는 복사해 보관하므로 원본을 이동해도 계속 표시합니다.

기존 기능
• 외부 파일/바로가기를 설정창으로 끌거나 ‘파일 등록’으로 추가합니다.
• 항목 우클릭 → 편집에서 이름, 아이콘, 메모, 실행 인수, 작업 폴더를 수정합니다.
• 실제 폴더 경로와 https:// 주소, steam:// 링크도 등록할 수 있습니다.
• 기본 아이콘은 Windows가 제공하는 파일/바로가기 아이콘을 사용합니다.
• Home: 라이브러리 / Esc: 상위 폴더, 루트에서는 숨기기 / Ctrl+F: 설정.
• ×: 런처 숨기기 / ⚙ 우클릭 → 런처 종료: 완전히 종료.
• 설정창의 ‘··· → 실행 후 런처 숨기기’로 원하는 동작을 선택합니다.
• 다른 앱을 열거나 선택하면 일반 앱처럼 그 창 뒤로 갑니다.
• 부채꼴은 작업표시줄 런처 버튼의 중앙과 작업 영역 하단에 맞춥니다.
  Windows가 버튼 정보를 제공하지 않는 경우 작업표시줄 클릭 위치 등의
  대체 위치를 사용합니다. 실제 작업표시줄 버튼 탐색은 작업 환경 제한으로
  직접 검증하지 못했으며 배치 계산과 화면 배율 처리는 자동 검사했습니다.
• 둥근 주아(Jua)와 고운돋움 글꼴을 Fonts 폴더에 포함했습니다.

저장, 백업과 보관 위치
• 요청하신 바탕화면 ‘작업표시줄 런처 (6.1sol)’ 폴더에 모두 보관했습니다.
• 소스: C# 소스, 빌드 스크립트, 글꼴과 라이선스.
• 실행파일: 현재 적용한 런처와 Fonts, 개인 Data.
• 실행파일\Data\library.json: 등록 정보와 테마/배경 설정.
• 실행파일\Data\library.json.bak: 직전 저장본.
• 실행파일\Data\icons: 복사한 아이콘과 전체/칸별 배경 이미지.
• 중간파일: 빌드, 검증, 예시 미리보기, 작업 과정 파일.
• 중간파일\이전버전-v3: 이전 소스, 배포 ZIP, 사용 안내, 등록 정보.
  ‘적용직전\Data’에 교체 바로 전의 등록 정보를 추가로 보관했습니다.
• ‘··· → 라이브러리 백업’은 메모/아이콘/전체·칸별 배경/테마를 포함합니다.
  실제 실행 프로그램과 문서 원본은 백업에 포함하지 않습니다.
• 등록 해제는 목록만 지우며 실제 파일을 삭제하지 않습니다.
• 작업표시줄 런처.zip은 v4 배포본으로 개인 등록 정보를 포함하지 않습니다.
• 실행파일 위치를 옮기면 작업표시줄에 다시 고정해야 합니다.

확인한 내용
• 91개 자동 검사와 3개 적용 후 검사, 총 94개 검사를 통과했습니다.
• 실제 드롭 이벤트의 순서 변경/폴더 이동, 실제 휠과 마우스 올림·이탈,
  순환 방향과 폴더별 위치 기억, 중첩 폴더 메뉴, 6개 테마와 커스텀 색상,
  잘못된 색상 입력 차단, 전체/칸별 배경의 적용·취소와 자르기,
  백업·복원, 글꼴, 일반 창 설정, 실행 파일 시작과 중복 실행 연결,
  기존 12개 항목과 설정 보존을 확인했습니다.
• 예시 화면은 별도 테스트 자료이며 실제 등록 정보에 추가하지 않았습니다.
• 현재 PC의 .NET Desktop Runtime 6.0으로 실행합니다.
• .NET 6 SDK가 있는 환경에서 소스\빌드.ps1로 다시 빌드할 수 있습니다.
  실행 중인 런처를 종료하거나 빌드 출력 폴더를 따로 지정하세요.
