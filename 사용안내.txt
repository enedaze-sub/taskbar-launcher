작업표시줄 런처 v5 — 선택형 휠 · 디자인과 커스텀 테마

현재 실행파일에 업데이트를 적용했습니다.
기존 바탕화면 바로가기와 작업표시줄 고정 아이콘을 계속 사용할 수 있습니다.
26개 등록 항목의 이름, 순서, 폴더 소속, 메모, 경로, 실행 인수,
아이콘과 칸별 배경을 이전/이후로 비교해 그대로 유지했습니다.
현재 커스텀 색상·배치, 전체 배경과 실행 후 숨기기 설정도 보존했습니다.

페이지 버튼이 기본, 휠은 필요할 때 켜기
• 기본값은 ‘휠로 다이얼 돌리기’ 꺼짐입니다.
• 휠을 돌려도 런처의 표시 위치가 바뀌지 않습니다.
• 이전/다음 페이지 버튼이나 PageUp / PageDown으로 이동합니다.
• 켜기: ⚙ → 설정창 ‘···’ → ‘휠로 다이얼 돌리기’ 체크.
• 켜면 휠 아래: 다음 항목 / 위: 이전 항목으로 한 칸씩 회전합니다.
  첫 항목과 마지막 항목이 이어지며 페이지 버튼도 계속 사용할 수 있습니다.
• 체크를 해제하면 다시 버튼 중심으로 사용합니다.
• 설정은 재실행과 백업 시 유지합니다. 이번 업데이트에서는 기본으로 꺼 두었습니다.

기본 색상 6종, 새 디자인 4종, 내 커스텀 테마
• ⚙ → ‘꾸미기’ → ‘테마 / 색상 / 배치’로 엽니다.
• ‘기본 색상 · 6’, ‘새 디자인 · 4’, ‘내 커스텀 테마’가 따로 있습니다.
• 기본 색상: 민트 나이트, 라벤더 문, 딸기 밀크, 바닐라 라테,
  오션 블루, 네온 오빗. 기존 6종은 계속 유지합니다.
• 모던 스튜디오: 밝은 바탕, 얇은 구분선, 단정한 아이콘 프레임.
• 고양이 다락: 크림색 바탕, 아이콘의 고양이 귀, 중앙 얼굴과 발바닥.
• 네온 아케이드: 어두운 바탕, 발광 테두리, 빛나는 원형 프레임.
• 글래스 스카이: 푸른 유리 느낌, 투명한 프레임, 반사 하이라이트.
• 오른쪽에서 디자인 스타일, 바탕/칸/포인트/글자 색, 아이콘 모양,
  크기·위치, 칸 수(5~9), 칸 사이 여백, 이름·메모 표시를 조절합니다.
• 색상 동그라미로 고르거나 #RRGGBB 코드를 입력합니다.
• 실제 부채꼴 미리보기에 변경 결과를 바로 반영합니다.

별도로 커스텀 테마 저장하기
1. ‘내 커스텀 테마’ → ‘＋ 새 커스텀’.
2. 오른쪽에서 원하는 디자인, 색상, 배치를 편집합니다.
3. 오른쪽 아래 ‘커스텀 테마 이름’을 입력합니다.
   오른쪽 편집 영역은 아래로 스크롤할 수 있습니다.
4. ‘내 커스텀 테마에 보관’을 누른 뒤 ‘적용’으로 마무리합니다.
• 보관 버튼을 따로 누르지 않아도 변경한 테마에 ‘적용’을 누르면
  입력한 이름으로 커스텀 목록에 저장합니다.
• 여러 이름의 테마를 저장하고 상단 목록에서 다시 선택할 수 있습니다.
• 저장된 테마를 선택하고 수정하면 같은 항목을 갱신합니다.
  새 사본을 만들려면 ‘＋ 새 커스텀’을 누르세요.
• ‘선택 테마 삭제’는 선택한 커스텀 항목만 지웁니다.
• 기본 6종과 새 디자인 4종은 커스텀 저장/삭제로 바뀌지 않습니다.
• ‘취소’하면 이 편집창에서 저장·삭제한 변경도 되돌립니다.
• 이전 버전의 커스텀 모양을 현재 모습 그대로 유지하면서
  ‘내 커스텀 테마’ 목록에 한 번만 추가해 두었습니다.
• 커스텀 목록과 선택한 디자인은 재실행과 라이브러리 백업에 포함됩니다.

폴더 아이콘 시안 — 직접 확인한 뒤 적용하세요
• 작업 폴더에 ‘폴더 아이콘 시안’ 폴더를 새로 만들었습니다.
• 게임 / Ai / 메신저 / 유틸 / 디코봇에 맞춘 5개 이미지가 있습니다.
• imagegen 내장 도구로 제작한 1254×1254 투명 배경 PNG입니다.
• 전체 미리보기, 40px 크기 비교와 최종 제작 프롬프트도 동봉했습니다.
• 런처에는 적용하지 않았습니다. 기존 아이콘도 유지했습니다.
• 적용: 폴더 우클릭 → 편집 / 아이콘 변경 → 이미지 선택 → 저장.

계속 사용할 수 있는 정리와 배경 기능
• 카드 가장자리에 드래그: 앞/뒤 표시 순서 변경.
• 폴더 카드 가운데에 드래그: 폴더 안으로 넣기.
• 상위 경로, 왼쪽 라이브러리/폴더 목록, 뒤로 버튼: 폴더 밖으로 꺼내기.
• 부채꼴에서도 칸 가장자리는 순서 변경, 폴더 가운데는 안으로 넣기입니다.
• 폴더에 마우스를 올리면 옆으로 내용이 열리며 하위 폴더도 펼칠 수 있습니다.
• 전체 배경: ‘꾸미기’ → ‘전체 배경 이미지’.
• 칸별 배경: 카드/아이콘 우클릭 → ‘이 칸의 배경 이미지’.
• 미리보기에서 드래그로 위치를 맞추고 휠/슬라이더로 확대합니다.
  가로/세로 위치와 어둡게 정도는 이미지별로 저장합니다.
• 아이콘 이미지와 칸의 배경은 별도로 설정합니다.
• ‘적용’으로 저장, ‘취소’로 유지, ‘기본 배경’ → 적용으로 해당 이미지만 해제.
• 선택한 이미지는 복사하여 보관하므로 원본을 이동해도 표시합니다.
• PNG / JPG / JPEG / BMP / GIF 지원. GIF는 정지 이미지로 표시합니다.
• 항목 우클릭 → 편집에서 이름, 메모, 아이콘, 인수, 작업 폴더를 수정합니다.
• 실제 파일/바로가기를 끌어 등록하거나 ‘파일 등록’을 사용하세요.
• 기본 아이콘은 Windows 파일/바로가기 아이콘을 읽습니다.
• Home: 라이브러리 / Esc: 상위 폴더, 루트에서는 숨기기 / Ctrl+F: 설정.
• ×: 숨기기 / ⚙ 우클릭 → 런처 종료: 완전히 종료.
• 다른 앱을 선택하면 일반 앱처럼 그 창 뒤로 놓입니다.
• 부채꼴은 작업표시줄 런처 버튼 위치에 중앙을 맞춥니다.
  버튼 위치를 얻지 못하면 클릭 위치 등의 대체 위치를 사용합니다.
  실제 작업표시줄 탐색은 작업 환경에서 직접 확인하지 못했으며
  화면 배율, 밑변 위치와 배치 계산은 자동 검사했습니다.

저장과 백업
• 모두 요청하신 바탕화면 ‘작업표시줄 런처 (6.1sol)’ 폴더에 보관했습니다.
• 소스: 수정 가능한 C# 소스와 빌드 스크립트, 글꼴·라이선스.
• 실행파일: 업데이트한 런처, Fonts와 개인 Data.
• 실행파일\Data\library.json: 등록 정보, 배경, 테마 목록과 휠 설정.
• 실행파일\Data\library.json.bak: 직전 저장본.
• 실행파일\Data\icons: 복사한 아이콘과 전체/칸별 배경 이미지.
• 중간파일: 빌드, 자동 검사, 작업 과정과 예시 미리보기.
• 중간파일\이전버전-v4: 이전 소스, 안내문, 배포 ZIP과 개인 Data.
  적용직전\Data에는 교체 바로 전 등록 정보를 추가로 보관했습니다.
• 설정창 ‘··· → 라이브러리 백업’으로 메모, 아이콘, 배경,
  커스텀 테마와 설정을 함께 백업할 수 있습니다.
• 실제 실행 프로그램과 문서 원본은 백업에 포함하지 않습니다.
• 등록 해제는 런처 목록만 지우며 실제 파일은 삭제하지 않습니다.
• 배포 ZIP에는 개인 Data를 포함하지 않습니다.
• 실행파일 위치를 옮기면 작업표시줄에 다시 고정해야 합니다.
• 둥근 주아(Jua)와 고운돋움 글꼴을 Fonts 폴더에 포함했습니다.

검증
• 113개 자동 검사, 4개 적용 후 검사, 5개 아이콘 검사로 총 122개 통과.
• 기본 휠 차단과 설정 토글/저장, 페이지 버튼과 휠 순환,
  실제 드롭과 폴더 펼치기, 별도 커스텀 생성/수정/선택/삭제/취소,
  재실행과 백업 복원, 이전 테마 이전, 새 디자인, 이미지 투명도를 확인했습니다.
• 26개 실제 등록 항목, 기존 아이콘과 배경, 커스텀 색상·배치를 보존했습니다.
• 예시 화면과 새 아이콘을 개인 라이브러리에 자동 등록하지 않았습니다.
• 현재 PC의 .NET Desktop Runtime 6.0으로 실행합니다.
• .NET 6 SDK가 있으면 소스\빌드.ps1로 다시 빌드할 수 있습니다.
  실행 중인 런처를 종료하거나 빌드 출력 폴더를 따로 지정하세요.
