작업표시줄 런처 v2 — 부채꼴 UI

시작하기
• 바탕화면의 ‘작업표시줄 런처 (6.1sol)’ 폴더에서
  ‘작업표시줄 런처.lnk’를 실행하세요.
• 압축 파일을 풀어 사용한다면 실행파일\DeckLauncher.exe를 실행하세요.
• 기존 작업표시줄 고정 아이콘과 실행용 바로가기는 그대로 사용합니다.
• 새로 고정할 때는 실행 중 작업표시줄 아이콘을 우클릭하고
  ‘작업 표시줄에 고정’을 선택하세요.

새 실행 화면
• 실행하면 작업표시줄 위에 반원 부채꼴 메뉴가 펼쳐집니다.
• 창의 바깥 부분은 투명하며, 부채꼴 안에 아이콘이 배치됩니다.
• 기본 글꼴은 컴퓨터에 설치된 Noto Sans KR입니다.
  해당 글꼴이 없는 PC에서는 Segoe UI / 맑은 고딕으로 대체됩니다.
• 마우스를 올린 항목은 청록색으로 강조되며 가운데에 이름과 메모가 표시됩니다.
• 프로그램이나 파일을 한 번 클릭하면 실행합니다.
• 폴더를 클릭하면 같은 부채꼴 안에 내부 항목이 나타납니다.
• 아래 왼쪽 화살표로 상위 폴더로 돌아갑니다.
• 한 페이지에 최대 7개 항목을 표시합니다.
  항목이 더 많으면 마우스 휠, 아래 화살표, PageUp / PageDown으로 넘깁니다.
• 폴더를 나갔다가 돌아오면 마지막 페이지를 기억합니다.
• 아래 × 버튼은 숨기기입니다. Esc는 상위 폴더로 이동하며 루트에서는 숨깁니다.
• 다른 창을 선택하면 메뉴가 숨겨집니다.
• 기본적으로 항목 실행 후에도 메뉴가 숨겨집니다.
  설정창의 ‘··· → 실행 후 런처 숨기기’에서 변경할 수 있습니다.
• 고정한 아이콘이나 실행용 바로가기로 다시 열 수 있습니다.

파일 등록과 폴더 구성
• 가운데 아래의 청록색 ⚙ 버튼을 클릭하면 설정창이 열립니다.
• ‘＋ 파일 등록’으로 여러 파일을 한 번에 등록하거나,
  설정창에 실행 파일, 바로가기(.lnk), 문서, 실제 폴더를 끌어다 놓으세요.
• 실제 폴더는 파일 탐색기로 여는 바로가기로 등록됩니다.
• ‘＋ 폴더’는 분류용 가상 폴더를 만듭니다.
• 가상 폴더 안에서 다시 ‘＋ 폴더’를 누르면 하위 폴더를 만듭니다.
• 항목 우클릭 → ‘폴더로 이동’으로 분류합니다.
• ‘앞으로 이동 / 뒤로 이동’으로 같은 폴더 안의 순서를 바꿉니다.
• 설정창의 × 버튼은 설정창만 닫고 부채꼴 메뉴로 돌아갑니다.
• Ctrl+F는 실행 화면에서는 설정창을, 설정창에서는 검색 입력란을 엽니다.
• 검색은 전체 라이브러리의 이름, 메모, 경로, 폴더 이름을 대상으로 합니다.

아이콘과 메모
• 설정창에서 항목을 우클릭 → ‘편집 / 아이콘 변경’을 선택하세요.
• ‘마우스를 올렸을 때 표시할 메모’에 설명을 입력하고 저장하세요.
  폴더에도 메모를 설정할 수 있습니다. 짧은 두세 줄을 권장합니다.
• 긴 메모는 가운데에서 요약 표시되며, 잠시 마우스를 올려 두면
  별도의 설명 창에서 전체 내용을 볼 수 있습니다.
• 실행 화면에서 항목을 우클릭해 이름 / 이미지 / 메모를 바로 편집할 수도 있습니다.
• 기본 아이콘은 Windows의 파일 및 바로가기 아이콘을 사용합니다.
• ‘이미지 선택’으로 PNG / JPG / JPEG / BMP / ICO / GIF를 지정합니다.
  GIF는 정지 이미지로 표시됩니다.
• 사용자 지정 이미지는 Data\icons에 복사되어 원래 이미지를 옮겨도 유지됩니다.
• ‘기본 아이콘 사용’으로 되돌릴 수 있습니다.
• 파일 경로, 실행 인수, 작업 폴더도 편집할 수 있습니다.
• 설정창 ‘··· → 파일 경로 / 링크 직접 등록’에서 URL이나 steam:// 링크를 입력합니다.
  해당 링크를 처리하는 프로그램이 설치되어 있어야 합니다.

저장과 백업
• 기존 버전의 등록 정보와 사용자 지정 아이콘을 그대로 읽습니다.
• 등록 정보: 실행파일\Data\library.json
• 직전 저장본: 실행파일\Data\library.json.bak
• 사용자 지정 아이콘: 실행파일\Data\icons
• 설정창의 ‘··· → 라이브러리 백업’은 등록 정보, 메모, 아이콘을 ZIP으로 저장합니다.
• ‘백업 복원’은 현재 목록을 선택한 백업으로 교체합니다.
• 등록 해제는 런처 목록만 지웁니다. 실제 파일은 삭제하지 않습니다.
• 실행파일 폴더의 파일은 함께 보관해 주세요.
• 고정 후 실행 파일 위치를 옮긴 경우 작업표시줄에 다시 고정하세요.
• 백업에 프로그램과 문서 원본은 포함되지 않습니다.
• 현재 PC에 설치된 .NET Desktop Runtime 6.0으로 실행되며 별도 설치가 필요 없습니다.

보관된 자료
• 실행파일: 최신 v2 실행 파일. 기존 Data 폴더를 유지합니다.
• 소스: 수정 가능한 C# 소스, 프로젝트, 빌드 스크립트
• 중간파일: 렌더링 예시, 검증결과, 테스트 및 빌드 자료
• 중간파일\이전버전-v1: 이전 소스와 배포 ZIP
• 작업표시줄 런처.zip: v2 배포용 압축 파일. 개인 등록 정보는 포함하지 않습니다.
• 미리보기는 예시 항목으로 제작했으며 실제 목록에 예시 항목을 추가하지 않습니다.

검증
• 41개 검사 통과: 기존 JSON 호환, 메모 저장과 백업, 파일/바로가기 아이콘,
  실제 프로세스 실행, 중첩 폴더, 검색, 실제 마우스 올림 이벤트,
  부채꼴 클릭 영역, 폴더 클릭, 페이지 이동과 기억, 투명 창,
  작업표시줄 연결 정보, 일반 시작 및 중복 실행 연결 등.
• 부채꼴, 메모 강조, 내부 폴더, 설정창, 편집창을 실제 WPF로 렌더링해 확인했습니다.

소스 다시 빌드
• .NET 6 SDK가 있는 환경에서 소스\빌드.ps1을 실행합니다.
• 설치된 참조 라이브러리만 사용하며 외부 패키지를 다운로드하지 않습니다.
• 소스를 빌드하기 전 설정창 ‘··· → 런처 종료’로 종료하세요.
