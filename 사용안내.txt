작업표시줄 런처 v8 — UI 디자인 6종 새 단장

꾸미기 → 색상 · UI 디자인 → ‘UI 디자인 · 6’에서 실제 모습의 축소판을 보고 고르세요.
디자인과 색상은 서로 독립입니다. 디자인을 바꿔도 지금 색상이 유지되고,
‘이 디자인의 추천 색상 쓰기’를 누르면 그 디자인용으로 만든 색 조합이 적용됩니다.
현재 쓰시던 기본 부채꼴 + 내 커스텀 테마 설정은 그대로입니다.

• 기본 부채꼴 — 칸과 바탕에 은은한 방사형 그라데이션을 넣어 입체감을 더했습니다.
• 냥냥 포켓 — 둥근 고양이 얼굴(반짝이는 눈, 볼터치, ω 입, 수염, 이마 무늬),
  둥근 귀, 살랑 꼬리, 하단 바를 붙잡은 앞발, 발바닥 무늬가 찍힌 쿠션형 칸.
• 사이버 HUD — 육각형 노드, 격자 배경과 주사선, 레이더 원·눈금, 모서리 브래킷.
• 다이어리 스크랩 — 스프링 노트와 뒷장, 줄 노트·여백선, 색색 포스트잇 칸,
  마스킹 테이프와 접힌 모서리, 별·하트 낙서, 점선 하단 바.
• 글래스 도크 — 떠 있는 제목 캡슐과 반투명 유리 도크, 아이콘 그림자,
  마우스를 올리면 아이콘이 크게 커지는 효과.
• 별빛 궤도(신규) — 별이 뜬 하늘 돔, 궤도를 따라 도는 행성 모양 아이콘,
  고리를 두른 큰 행성 위의 버튼, 반짝이는 별과 별똥별.

• 장식은 모두 테마 색에서 계산한 벡터 그림이라 어떤 색 팔레트와도 어울립니다.
• 장식도 가운데(x=460) 기준 좌우 대칭으로 배치했습니다(고양이 귀·수염·앞발, 노트 링, HUD 브래킷 등).
• 색상 팔레트는 10종: 새 디자인에 맞춰 4종을 다듬고 ‘별빛 보라’를 추가했습니다.
• 자동 검사 157개 통과. 새 미리보기: 디자인6종-미리보기.png, 테마설정-미리보기.png.

작업표시줄 런처 v7 — 디자인 정리 · 직접 등록 · 글꼴 선택

현재 실행파일에 업데이트를 적용했습니다. 등록 항목, 테마, 배경은 그대로입니다.
v6 소스와 실행파일은 중간파일\이전버전-v6에 보관했습니다.

런처 설정 창
• 설정 창 기본 글꼴을 Noto Sans KR(Windows 기본 탑재, 없으면 맑은 고딕)로 바꿨습니다.
  제목은 굵게, 설명은 대비를 높여 작은 글자도 또렷하게 보입니다.
• 상단 버튼: 파일 등록 · 직접 등록 · 새 폴더 · 꾸미기 · 런처 옵션(···) · 닫기.
  모든 아이콘은 Segoe 아이콘 글꼴로 바꿔 버튼 안에서 가운데에 오도록 정렬했습니다.
• 파일을 창으로 끌어 오면 ‘여기에 놓으면 바로 등록돼요’ 안내가 표시됩니다.
• 왼쪽 폴더 목록에 폴더 아이콘과 항목 수를 표시합니다.
• 버튼, 입력칸, 체크박스, 스위치, 슬라이더, 스크롤바, 툴팁, 우클릭 메뉴를 테마 색에 맞췄습니다.
• Windows 11에서는 설정·편집 창의 제목 표시줄도 테마 색을 따릅니다.

직접 등록 (기존 ‘? 등록 도움말’ + ‘주소로 직접 등록’ 통합)
• 런처 설정 상단의 ‘직접 등록’ 하나로 합쳤습니다. ··· 메뉴의 중복 항목은 제거했습니다.
• 방법 1(추천): 실행 파일(.exe)이나 바로가기를 런처 설정 창에 끌어다 놓기.
  창 오른쪽 점선 칸에 놓거나, 점선 칸을 클릭해 파일을 골라도 됩니다.
• 방법 2: 작업표시줄 아이콘 우클릭 → 앱 이름 한 번 더 우클릭 → 속성 → ‘대상’ 복사
  → 오른쪽 ‘파일 경로 또는 URL’에 붙여넣기 → 등록.
  .exe 뒤의 --processStart 같은 옵션은 실행 인수로 자동 분리되고 이름도 자동으로 채웁니다.
  (Update.exe --processStart Discord.exe → 이름 ‘Discord’)
• 예시 화면 1은 새로 보내주신 Discord 우클릭 화면으로 교체했습니다.
• 편집 창의 ‘대상 주소 찾는 법’은 등록 칸 없이 안내만 보여 줍니다.

런처 옵션 (···)
• ‘동작 / 라이브러리 / 앱’으로 묶은 목록형 메뉴로 다시 만들었습니다.
• 휠 다이얼은 스위치로 켜고 끕니다. 런처 종료는 빨간색으로 구분했습니다.

글꼴 선택 (꾸미기 → 글꼴)
• ‘런처 글꼴’(제목, 아이콘 이름, 메모)과 ‘설정 창 글꼴’(설정, 메뉴, 도움말)을 따로 고릅니다.
• 이 PC에 설치된 한글 글꼴과 동봉 글꼴(주아, 고운돋움)이 모두 나오며 이름으로 검색할 수 있습니다.
• 실제 런처 미리보기와 설정 창 미리보기로 확인한 뒤 적용하세요. ‘모두 기본값으로’로 되돌립니다.
• 선택한 글꼴은 라이브러리 저장과 백업에 포함됩니다.
  다른 PC에 해당 글꼴이 없으면 기본 글꼴로 자동 대체합니다.

아이콘 · 대칭 위치 점검 결과와 수정
• 하단 버튼: 홈/상위 폴더와 숨기기 버튼이 가운데에서 79px / 75px로 어긋나 있던 것을
  양쪽 77px로 맞췄습니다. 이전/다음 페이지 버튼도 124px / 128px → 양쪽 126px.
• 네온 노드: 아이콘이 원형 노드 중심보다 5px 위에 있던 것을 원 중심에 맞췄고,
  ‘ORBIT / LAUNCH’ 문구가 위쪽 아이콘과 겹치던 것을 가운데 정렬해 위로 올렸습니다.
• 카드 보드: 상단 점 줄이 가운데에서 5.5px 왼쪽으로 치우쳐 있던 것을 좌우 대칭으로 고쳤고,
  제목이 점 줄에 붙어 있던 간격을 넓혔습니다.
• 고양이 포켓: 아이콘이 프레임보다 커서 삐져나오던 것을 프레임 안 여백이 같도록 조정,
  폴더 숫자 배지를 칸 오른쪽 세로 가운데로, 발바닥 무늬를 좌우 대칭(±304px)으로 옮겼습니다.
• 모던 도크 · 카드 보드: 아이콘과 이름 묶음이 칸 세로 가운데에 오도록 계산합니다.
• 폴더 숫자 배지는 숫자가 원 가운데에 오도록 고정 크기 원으로 바꿨습니다.
• 칸 배경 이미지가 있는 칸의 이름에는 반투명 받침을 넣어 어떤 이미지에서도 읽히게 했습니다.
• 기본 부채꼴의 아이콘·이름은 각 칸의 각도/반지름 중심에 정확히 놓여 있음을 확인했습니다.

보관과 검증

작업표시줄 런처 v6 — UI 레이아웃 · 설정창 색상 · 등록 도움말

현재 실행파일에 업데이트를 적용했습니다.
기존 바탕화면 바로가기와 작업표시줄 고정 아이콘을 그대로 사용할 수 있습니다.
등록된 27개 항목의 순서, 이름, 폴더 소속, 경로, 인수, 메모, 아이콘,
칸별 배경을 업데이트 전후로 비교해 보존했습니다.
기존 커스텀 색상과 배치도 유지했습니다.

색상과 UI 모양을 별도로 고르기
• ⚙ → ‘꾸미기’ → ‘색상 · UI 디자인’을 엽니다.
• 기본 색상은 9종입니다. 오션 블루와 글래스 스카이는 목록에서 제거했습니다.
• 민트 나이트, 라벤더 문, 딸기 밀크, 바닐라 라테, 네온 오빗에 더해
  클라우드 화이트, 피치 크림, 네온 민트, 크림 페이퍼를 추가했습니다.
• 색상을 바꿔도 선택한 UI 형태가 유지되며, UI를 바꿔도 색상이 유지됩니다.
• 색상은 런처 설정창, 편집창, 배경 편집, 도움말과 메뉴에도 연결됩니다.
• 기본 부채꼴도 계속 사용할 수 있습니다.

새 UI 디자인 4가지
• 모던 도크: 낮고 넓은 둥근 도크 안에 아이콘 타일을 가로로 나열합니다.
• 고양이 포켓: 고양이 귀와 수염이 있는 외형 안에 포켓형 아이콘을 배치합니다.
• 네온 노드: 각진 네온 프레임에 원형 노드와 연결선을 배치합니다.
• 카드 보드: 노트처럼 보이는 패널에 카드들을 여러 줄로 정렬합니다.
• ‘새 디자인 · 4’에서 선택하고 실제 미리보기를 확인한 뒤 ‘적용’하세요.
• 오른쪽 ‘디자인 스타일’에서도 형태를 바꿀 수 있습니다.
• 모든 레이아웃에서 클릭, 메모, 폴더 펼치기, 드래그 정렬과 페이지 이동을 지원합니다.
• 이름·메모 표시, 아이콘 크기와 칸 수는 기존처럼 조절합니다.

커스텀 테마
• ‘내 커스텀 테마’에서 이름을 붙여 여러 개 저장할 수 있습니다.
• ‘＋ 새 커스텀’ → 디자인/색상/배치 변경 → 이름 입력 → 적용.
• 저장한 테마를 선택하고 편집하면 해당 항목을 갱신합니다.
• 색상 목록과 기본 UI 디자인은 커스텀 저장·삭제로 바뀌지 않습니다.
• 취소하면 저장·삭제를 포함한 편집창의 변경을 되돌립니다.
• 선택한 모습과 커스텀 목록은 재실행과 라이브러리 백업에 포함됩니다.

파일 등록 도움말
• ‘파일 등록’ 옆에 ‘? 등록 도움말’을 추가했습니다.
• 주소 등록 편집창에도 도움말 버튼이 있습니다.
• 첨부해 주신 예시 화면을 사용한 3단계 안내입니다.
  1. 실행 중인 앱의 작업표시줄 아이콘 우클릭.
     나타난 앱 이름/아이콘을 한 번 더 우클릭 → 속성.
  2. 바로 가기 탭 → 대상 클릭 → Ctrl+A → Ctrl+C로 전체 복사.
  3. 런처 옵션(···) → 주소로 직접 등록 → 파일 경로 또는 URL에 Ctrl+V → 저장.
• 화면이 작으면 ‘예시 화면 크게 보기’를 누르세요.
• Discord처럼 .exe 뒤에 --processStart 등의 옵션이 있으면 대상 전체를 복사하세요.
  실제 붙여넣기 때 파일 경로와 실행 인수로 자동 분리합니다.
• 탐색기의 바로가기(.lnk)도 속성 → 바로 가기 → 대상에서 복사할 수 있습니다.
• 실제 .exe에는 대상 칸이 없습니다. Shift+우클릭 → 경로로 복사를 이용하거나
  파일 자체를 런처 설정창으로 끌어 넣으세요.
• 파일 선택창으로 등록하거나 파일/바로가기를 끌어 넣는 기능도 유지합니다.

자동 숨김
• 런처 아이콘으로 앱을 성공적으로 실행하면 런처를 숨깁니다.
• 런처 바깥을 클릭하거나 다른 앱으로 포커스를 옮기면 숨깁니다.
• 처음부터 런처가 활성화되지 않았던 경우에도 바깥 클릭을 처리합니다.
• 폴더 메뉴나 설정창 내부를 조작하는 동안에는 유지됩니다.
• 실행 오류가 나면 오류를 확인하고 등록 정보를 고칠 수 있습니다.
• 숨김은 종료가 아닙니다. 기존 작업표시줄 아이콘을 클릭하면 다시 열립니다.
• 완전 종료는 런처 옵션(···) → 런처 종료입니다.

글꼴과 메뉴
• 이 컴퓨터에 설치된 카페24 써라운드를 제목·아이콘 이름·중앙 문구에 사용합니다.
• 설정 본문과 입력은 카페24 써라운드 에어를 사용합니다.
• 중앙 안내·메모의 크기와 대비를 높여 읽기 쉽게 조정했습니다.
• 다른 컴퓨터에서 해당 글꼴이 없으면 동봉한 주아/고운돋움으로 대체합니다.
  카페24 글꼴 파일을 별도로 복사하거나 재배포하지 않았습니다.
• 꾸미기와 옵션은 둥근 카드, 설명, 아이콘이 있는 테마 연동 선택창입니다.
• 항목 우클릭 메뉴, 입력칸과 선택 목록도 테마에 맞게 조정했습니다.

기존 기능
• 휠 다이얼은 기본 꺼짐입니다. 옵션(···)에서 ‘휠로 다이얼 돌리기’를 켭니다.
• 기본은 이전/다음 페이지 버튼과 PageUp / PageDown입니다.
• 휠을 켜면 한 칸씩 이전/다음 항목이 순환합니다.
• 설정 카드 가장자리로 드래그: 앞/뒤 순서 변경.
• 폴더 카드 가운데로 드래그: 안으로 넣기.
• 상위 경로/왼쪽 폴더 목록/뒤로 버튼으로 드래그: 밖으로 꺼내기.
• 새 UI에서도 칸 가장자리와 폴더 가운데를 구분합니다.
• 폴더에 마우스를 올리면 옆으로 내부 아이콘이 표시되고 하위 폴더도 펼칩니다.
• 전체 배경: 꾸미기 → 전체 배경 이미지.
• 칸별 배경: 카드/아이콘 우클릭 → 이 칸의 배경 이미지.
• 실제 미리보기에서 드래그로 위치를 맞추고 확대·어둡게 정도를 조절합니다.
• 이미지별 위치와 확대 값은 따로 저장합니다.
• 이미지 위에 표시되는 설정 카드 이름은 바탕판으로 가독성을 보완했습니다.
• PNG/JPG/JPEG/BMP/GIF 지원. GIF는 정지 이미지로 표시됩니다.
• 등록 해제는 런처 목록만 지우며 실제 파일은 삭제하지 않습니다.
• Home: 라이브러리 / Esc: 상위 폴더, 루트에서는 숨기기 / Ctrl+F: 설정.

보관과 검증
• 모든 자료는 요청하신 바탕화면 ‘작업표시줄 런처 (6.1sol)’ 폴더에 저장했습니다.
• 소스: 수정 가능한 소스, 빌드 스크립트, 글꼴과 도움말 이미지.
• 실행파일\Data\library.json: 개인 등록 정보와 화면 설정.
• 실행파일\Data\library.json.bak: 직전 저장본.
• 실행파일\Data\icons: 복사한 아이콘과 배경 이미지.
• 중간파일\이전버전-v5: 이전 소스, 개인 Data, 안내문과 배포 ZIP.
  적용직전\Data에 교체 바로 전 정보를 추가 보관했습니다.
• 중간파일\검증-v6: 138개 자동 검사와 3개 적용 후 검사, 총 141개 통과 기록.
• 새 UI의 클릭 영역/정렬, 도움말 이미지와 실제 붙여넣기 처리,
  설정 색상, 테마와 UI의 독립 선택, 바깥 클릭/앱 실행 후 숨김,
  폴더/메모/배경/백업/복원과 기존 27개 등록 정보 보존을 확인했습니다.
• 디자인4종, 도움말, 설정 색상, 꾸미기/옵션의 예시 PNG도 함께 보관했습니다.
• 배포 ZIP에는 개인 Data를 포함하지 않습니다.
• 이전 ‘폴더 아이콘 시안’은 그대로 보관했고 이번 업데이트에서 자동 적용하지 않았습니다.
• 현재 PC의 .NET Desktop Runtime 6.0으로 실행합니다.
• .NET 6 SDK가 있으면 소스\빌드.ps1로 다시 빌드할 수 있습니다.
  실행 중인 런처를 종료하거나 출력 폴더를 따로 지정하세요.
• 실제 작업표시줄 버튼 탐색은 작업 환경 제한으로 직접 확인하지 못했습니다.
  작업 영역/배율/밑변 배치 계산을 검사했고, 버튼 위치가 없으면 대체 위치를 사용합니다.
