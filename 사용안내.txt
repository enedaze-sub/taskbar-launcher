작업표시줄 런처 v3 — 드래그 이동 · 배경 꾸미기

시작하기
• 같은 바탕화면 폴더의 ‘작업표시줄 런처.lnk’를 다시 실행하세요.
• 기존 작업표시줄 고정 아이콘도 그대로 사용할 수 있습니다.
• 실제 사용 중이던 12개 항목의 이름, 경로, 폴더 소속, 메모, 아이콘,
  실행 인수, 작업 폴더, 순서를 업데이트 전후로 비교해 보존했습니다.
• 이전 소스, 배포 ZIP, 등록 정보는 중간파일\이전버전-v2에 보관했습니다.

드래그로 정리하기
• 설정창: 항목을 누른 채 폴더 카드나 왼쪽 폴더 목록으로 끌어 넣으세요.
• 폴더 안에서 꺼내려면 위쪽 ‘라이브러리’ 경로, 상위 폴더 경로,
  뒤로 버튼 또는 왼쪽 라이브러리/다른 폴더 목록에 떨어뜨리세요.
• 부채꼴 실행 화면에서도 아이콘을 폴더 조각으로 끌어 넣을 수 있습니다.
• 부채꼴의 아래 왼쪽 뒤로 버튼에 떨어뜨리면 상위 폴더로 꺼냅니다.
• 폴더를 통째로 옮길 수도 있습니다. 자기 자신이나 하위 폴더에 넣는 이동은 막습니다.
• 드래그한 항목은 자동 저장됩니다. 실제 파일을 옮기지 않습니다.
• 설정창에서 외부 파일을 폴더에 끌어다 놓으면 해당 폴더에 등록됩니다.
• 기존 우클릭 → 폴더로 이동, 앞으로 / 뒤로 이동 기능도 계속 사용할 수 있습니다.

배경 이미지
1. 부채꼴 가운데 아래 ⚙ 버튼으로 설정창을 엽니다.
2. 위쪽 ‘배경 꾸미기’ 버튼을 누릅니다.
3. ‘이미지 선택’으로 PNG / JPG / JPEG / BMP / GIF 이미지를 고릅니다.
4. 실제 부채꼴 미리보기에서 이미지를 드래그해 위치를 맞춥니다.
   마우스 휠 또는 확대 / 축소 슬라이더로 1~4배까지 조절합니다.
5. 가로 위치, 세로 위치, 배경 어둡게 슬라이더로 마무리합니다.
6. ‘적용’을 누르면 배경 이미지가 복사되어 저장됩니다.
• 이미지는 부채꼴 밖으로 나오지 않도록 잘라 표시합니다.
• 빈 부분이 생기지 않도록 화면을 채웁니다. 이동 여유가 없을 때는 먼저 확대하세요.
• ‘취소’하면 실제 배경은 바뀌지 않습니다.
• ‘위치 초기화’는 확대와 위치를 기본값으로 되돌립니다.
• ‘기본 배경’ → 적용으로 이미지 없이 원래 색상으로 돌아갑니다.
• 선택한 이미지, 확대, 위치, 어둡게 값은 재실행 시 유지되고 ZIP 백업에도 포함됩니다.
• 저장 후 원래 이미지 파일을 이동해도 복사된 배경을 계속 사용합니다.

창 동작과 배치
• 런처, 설정창, 편집창, 배경 설정창 모두 항상 위 표시를 해제했습니다.
• 다른 창을 열거나 클릭하면 일반 앱처럼 그 창 뒤에 놓입니다.
• 실행 후 런처를 숨기는 설정도 업데이트 시 한 번 기본 해제했습니다.
  원한다면 설정창의 ‘··· → 실행 후 런처 숨기기’로 다시 켤 수 있습니다.
• 부채꼴 아래 빈 공간과 ‘아이콘에 마우스를 올려 메모 보기’ 문구를 제거했습니다.
• 화면 배율을 고려해 부채꼴의 실제 밑변을 작업표시줄 위쪽에 붙입니다.
• Windows가 제공하는 작업표시줄 런처 버튼 위치를 읽어 중앙을 맞춥니다.
  버튼 정보가 제공되지 않으면 마지막 위치, 작업표시줄 클릭 위치,
  작업 영역 중앙을 차례로 대체 위치로 사용합니다.
• 실제 작업표시줄 버튼 탐색은 이 작업 환경에서 직접 확인할 수 없었습니다.
  버튼 위치와 밑변 정렬 계산, 음수 좌표 모니터 배치는 자동 검사했습니다.
• Home: 라이브러리 / Esc: 상위 폴더로 이동, 루트에서는 숨기기
• 마우스 휠, PageUp / PageDown: 페이지 이동 (페이지마다 최대 7개 항목)
• ×: 숨기기 / ⚙ 우클릭 → 런처 종료: 완전히 종료

둥근 글꼴
• 아이콘 이름과 주요 제목: 배민 주아(Jua)
• 본문과 설정 입력: 고운돋움(Gowun Dodum)
• 컴퓨터에 있던 글꼴을 Fonts 폴더에 복사해 포함했습니다.
  설치 상태가 바뀌어도 같은 글꼴을 사용할 수 있습니다.
• Fonts\OFL.txt에 원본 저작권 표시와 SIL Open Font License를 포함했습니다.

메모와 아이콘
• 항목 우클릭 → 편집에서 간략한 메모와 이미지를 설정합니다.
• 마우스를 올리면 가운데에 메모가 보이며 긴 메모는 추가 설명 창으로 읽을 수 있습니다.
• 기본 아이콘은 파일/바로가기의 Windows 아이콘을 읽습니다.
• 사용자 지정 아이콘은 PNG / JPG / JPEG / BMP / ICO / GIF를 지원합니다.
• GIF는 정지 이미지로 표시됩니다.
• 파일 경로, 실행 인수, 작업 폴더도 편집할 수 있습니다.

저장과 백업
• 등록 정보와 화면 설정: 실행파일\Data\library.json
• 직전 저장본: 실행파일\Data\library.json.bak
• 복사한 아이콘과 배경 이미지: 실행파일\Data\icons
• 설정창의 ‘··· → 라이브러리 백업’으로 메모, 아이콘, 배경까지 백업합니다.
• 프로그램과 문서 원본은 백업에 포함되지 않습니다.
• 등록 해제는 목록만 지웁니다. 실제 파일은 삭제하지 않습니다.
• 실행파일 폴더와 Fonts 폴더를 함께 보관하세요.
• 실행 파일 위치를 옮기면 작업표시줄에 다시 고정해야 합니다.

보관된 자료와 검증
• 소스: 수정 가능한 C# 소스, 프로젝트, 빌드 스크립트, 글꼴
• 중간파일: 빌드 결과, 테스트 자료, 렌더링 미리보기, 검증결과
• 작업표시줄 런처.zip: v3 배포 파일. 개인 등록 정보나 배경은 포함하지 않습니다.
• 예시 화면은 별도 테스트 자료로 만들었으며 실제 등록 정보에 추가하지 않았습니다.
• 60개 검사 통과: 실제 폴더 드롭 이벤트와 꺼내기, 잘못된 이동 방지,
  메모, 배경 편집의 적용/취소 분리, 이미지 복사, 백업 복원, 폰트,
  일반 창 동작 설정, 작업표시줄 배치 계산, 일반 시작과 재실행 연결,
  실제 12개 등록 항목 보존 등을 확인했습니다.
• 현재 PC의 .NET Desktop Runtime 6.0으로 실행합니다.
• .NET 6 SDK가 있는 환경에서는 소스\빌드.ps1로 다시 빌드할 수 있습니다.
  소스를 빌드하기 전 런처를 완전히 종료하세요.
