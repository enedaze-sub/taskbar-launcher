DECK LAUNCHER — 작업표시줄 런처

시작하기
1. 이 폴더의 ‘작업표시줄 런처.lnk’를 두 번 클릭합니다.
   또는 실행파일 폴더의 DeckLauncher.exe를 실행합니다.
2. 창이 열린 상태에서 작업표시줄의 런처 아이콘을 우클릭하고
   ‘작업 표시줄에 고정’을 선택합니다.
3. 이후 작업표시줄 아이콘 하나로 런처를 열 수 있습니다.
   첫 실행 시 라이브러리는 비어 있습니다. 원하는 파일을 등록해 주세요.

파일 등록과 실행
• 실행 파일, 바로가기(.lnk), 문서 등을 창으로 끌어다 놓습니다.
• ‘＋ 파일 등록’으로 여러 파일을 한 번에 선택할 수도 있습니다.
• 실제 폴더를 끌어다 놓으면 파일 탐색기로 여는 바로가기로 등록됩니다.
• 카드를 한 번 클릭하면 등록한 항목이 실행됩니다.
• 같은 폴더에 같은 파일을 중복 등록하지 않습니다.
• ‘··· → 파일 경로 / 링크 직접 등록’에서는 URL이나 steam:// 링크도
  입력할 수 있습니다. 해당 링크를 처리하는 프로그램이 설치되어 있어야 합니다.

용도별 폴더
• ‘＋ 폴더’로 런처 안에서 사용할 폴더를 만듭니다.
• 폴더 안에서 다시 ‘＋ 폴더’를 누르면 하위 폴더가 생성됩니다.
• 항목을 우클릭하고 ‘폴더로 이동’을 선택해 분류합니다.
• 폴더 카드를 클릭하거나 왼쪽 폴더 목록을 눌러 내용을 확인합니다.
• 위쪽 경로와 뒤로 버튼으로 이동합니다.
• 우클릭 → 앞으로 이동 / 뒤로 이동으로 같은 폴더 안의 순서를 바꿉니다.
• 이 폴더들은 분류용 가상 폴더입니다. 실제 파일을 옮기지 않습니다.

이름과 아이콘
• 항목이나 폴더를 우클릭하고 ‘편집 / 아이콘 변경’을 선택합니다.
• 기본 상태에서는 Windows의 파일 아이콘을 표시합니다.
  바로가기 파일은 바로가기에 설정된 아이콘을 읽습니다.
• ‘이미지 선택’으로 PNG, JPG, JPEG, BMP, ICO, GIF 이미지를 지정합니다.
  GIF는 정지 이미지로 표시됩니다.
• 사용자 지정 이미지는 Data\icons에 복사됩니다.
  저장한 뒤 원래 이미지 파일을 이동해도 지정한 아이콘이 유지됩니다.
• ‘기본 아이콘 사용’을 누르면 원래 아이콘으로 돌아갑니다.
• 파일 경로, 실행 인수, 작업 폴더도 편집할 수 있습니다.

검색과 창 동작
• 검색은 현재 폴더뿐 아니라 전체 라이브러리를 대상으로 합니다.
  이름, 파일 경로, 상위 폴더 이름으로 검색할 수 있습니다.
• Ctrl+F: 검색 / Ctrl+N: 파일 등록
• Esc: 검색 지우기 → 상위 폴더로 이동 → 루트에서는 숨기기
• 카드에 키보드 포커스가 있을 때 F2: 편집 / Delete: 등록 해제
• Tab과 Enter로 카드 및 버튼을 선택할 수 있습니다.
• 기본적으로 항목 실행 후 창이 숨겨집니다.
  ‘··· → 실행 후 런처 숨기기’를 끄면 창을 계속 열어 둡니다.
• 숨겨진 창은 고정한 작업표시줄 아이콘이나 실행용 바로가기로 다시 엽니다.
  이미 실행 중이라면 새 프로세스를 추가로 유지하지 않습니다.
• 위쪽 제목 영역을 드래그하면 창이 이동합니다. 가장자리에서 크기를 조절합니다.
• ‘—’는 최소화, ‘×’와 ‘··· → 런처 종료’는 종료입니다.

저장과 백업
• 등록 정보와 설정: 실행파일\Data\library.json
• 직전 저장 정보: 실행파일\Data\library.json.bak
• 사용자 지정 아이콘: 실행파일\Data\icons
• ‘··· → 라이브러리 백업’은 등록 정보와 아이콘을 ZIP으로 저장합니다.
• ‘백업 복원’은 현재 목록을 백업 내용으로 교체합니다.
• 등록 해제는 런처 목록만 지웁니다. 실제 파일은 삭제하지 않습니다.
• 실행파일 폴더 안의 파일들은 함께 보관해 주세요.
  작업표시줄에 고정한 후 실행 파일 위치를 옮기면 다시 고정해야 합니다.
• 백업에는 프로그램이나 문서 원본이 포함되지 않습니다.
  다른 PC에서 복원한 경우 실제 파일 경로는 별도로 맞춰 주세요.

보관된 파일
• 작업표시줄 런처.lnk: 바로 실행하는 바로가기
• 실행파일: 실제 사용에 필요한 파일과 이후 저장되는 Data
• 소스: 수정 가능한 C# 소스, 프로젝트, 빌드 스크립트
• 중간파일: 빌드 자료, 테스트 데이터, 검증결과와 예시 화면
• 작업표시줄 런처.zip: 실행파일과 사용 안내를 담은 배포용 압축 파일
  미리보기의 예시 항목은 실제 라이브러리에 자동 등록되지 않습니다.

실행 환경
• Windows x64, 현재 PC에 설치된 .NET Desktop Runtime 6.0을 사용합니다.
• 현재 PC에서는 런타임을 새로 설치할 필요가 없습니다.
• 다른 PC에서는 호환되는 .NET Desktop Runtime이 필요합니다.
• 이 버전은 WPF로 만들었으며 별도 브라우저나 외부 서비스 없이 동작합니다.

소스 다시 빌드
• .NET 6 SDK가 있는 환경에서 소스\빌드.ps1을 실행합니다.
• 설치된 참조 라이브러리만 사용하므로 패키지를 다운로드하지 않습니다.
• 소스 수정 전에 런처를 종료하면 실행파일을 덮어쓸 수 있습니다.
• 일반 개발 도구에서는 DeckLauncher.csproj를 열어 작업할 수 있습니다.

검증
• 24개 검사 통과: 저장/복원, 중첩 폴더, 검색, 중복 방지,
  사용자 지정 아이콘, 기본/바로가기 아이콘, 실제 프로세스 실행,
  실행 인수/작업 폴더, 작업표시줄 재실행 연결 정보 등.
• 일반 실행 파일 시작과 재실행 시 기존 런처로 연결되는 동작도 확인했습니다.
• 화면을 실제 WPF로 렌더링해 라이브러리, 폴더, 아이콘 편집 배치를 확인했습니다.
• 작업표시줄 고정 자체는 사용자가 위 시작하기 절차에 따라 수행합니다.
