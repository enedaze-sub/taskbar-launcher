# DeckLauncher v8.3 · 100% 투명도와 테마 미리보기

Windows · Linux · macOS에 모두 적용했습니다.

## 완전 투명하게 설정하기

- **칸 우클릭 → 이 칸의 배경 이미지** 또는 **꾸미기 → 칸 배경 일괄 설정**에서 칸 투명도를 **-100~100%**로 조절합니다. 기존 85% 상한을 제거했습니다.
- 기본은 칸 전체를 함께 조절합니다. 100%면 칸의 배경·아이콘·글자가 모두 투명해집니다.
- **배경 · 아이콘 · 글자 투명도를 따로 조절**을 켜고, **칸 배경 100% / 아이콘 0% / 글자 0%**로 설정하면 배경만 완전히 사라지고 아이콘·글자는 선명하게 남습니다.
- **꾸미기 → 전체 배경 이미지**의 전체 런처 투명도도 **0~100%**로 확장했습니다. 이 값은 칸과 중앙 내용 전체에 함께 적용됩니다.
- 전체 런처가 100%여서 보이지 않을 때는 작업표시줄/Dock 아이콘을 누르면 설정창이 열립니다. 여기서 **꾸미기 → 전체 배경 이미지**의 투명도를 낮추면 다시 보입니다. 이 상태로 앱을 다시 시작해도 설정창을 열어 조절할 수 있습니다.
- 음수 칸 투명도와 일괄 적용 범위, 함께/따로 모드, 기존 문구·아이콘·이미지는 유지합니다. 실제 알파값이 0일 때도 저장·백업·복원이 가능합니다.

## 검증 및 설치

Windows 217개, Linux 132개, macOS 150개 검사를 통과했습니다. 완전 투명한 픽셀, 여섯 디자인에서의 배경·아이콘·글자 분리, 일괄 적용, 저장·백업·복원 및 설정창 복구를 확인했습니다.

Windows는 `.NET 6 Desktop Runtime x64`가 필요합니다. `taskbar-launcher-v8.3.zip`을 풀고 `실행파일/DeckLauncher.exe`를 실행합니다. 기존 런처를 종료한 뒤 기존 작업 폴더에 압축 내용을 덮어쓰면 됩니다. 개인 Data 폴더는 패키지에 포함하지 않으므로 기존 등록 정보는 유지됩니다.

Linux x86_64는 압축을 풀고 `bash install.sh --with-system-deps`를 실행합니다. Mac은 macOS 14.4+, Apple Silicon/Intel을 대상으로 하며 `install.command`로 `.app`을 만듭니다. 최초 빌드에는 Python 3.10~3.15와 Apple Command Line Tools가 필요합니다. Apple Developer ID 서명·공증은 포함하지 않습니다.

Linux/macOS는 Windows에서 Qt offscreen으로 검증한 미리보기 버전입니다. 실제 Ubuntu/Mac 설치·Dock 동작은 실기 검증 전입니다. OS별 자세한 설치 방법은 각 패키지의 README.md를 확인하세요.
