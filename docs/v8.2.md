# DeckLauncher v8.2 · 문구와 배경·투명도 설정

Windows, Linux, macOS에 동일한 꾸미기 기능을 반영했습니다.

## 칸 투명도 함께 / 따로 조절하기

1. **칸 우클릭 → 이 칸의 배경 이미지**를 엽니다.
2. 기본은 기존처럼 **칸 전체 / 배경 투명도**로 배경·아이콘·글자를 함께 조절합니다.
3. **배경 · 아이콘 · 글자 투명도를 따로 조절**을 켜면, 칸 슬라이더는 배경에만 적용됩니다. 아이콘과 글자는 각각 0~100%로 설정합니다. 0%는 선명하게, 100%는 보이지 않게 합니다.
4. 예: **배경 70% / 아이콘 0% / 글자 0%**로 설정하면 배경은 흐릿하고 아이콘·글자는 선명합니다.
5. 별도 조절을 끄면 함께 조절하기로 돌아옵니다. 별도로 지정했던 값은 보관되어 다시 켰을 때 사용할 수 있습니다.

칸 투명도 범위는 **-100~85%**입니다. 0%는 원래 디자인, 음수는 칸 바탕을 더 진하게, 양수는 더 투명하게 만듭니다. 런처 전체 투명도는 별도 설정 값 위에도 함께 적용됩니다. 아이콘 투명도는 아이콘 프레임과 폴더 개수 배지에도 적용되며, 글자 투명도는 이름과 이름 뒤의 읽기용 바탕에 적용됩니다.

## 일괄 설정과 문구 수정

- **꾸미기 → 칸 배경 일괄 설정**에서 전체 칸 / 현재 폴더의 칸 / 현재 폴더와 하위 폴더를 선택합니다. 이미지·위치와 투명도를 각각 선택해 적용합니다. 함께/따로 조절하기와 아이콘·글자 값도 일괄 적용됩니다.
- **투명도만 적용**하면 기존 이미지와 위치를 보존합니다. **이미지만 적용**하면 기존 투명도와 함께/따로 모드를 보존합니다.
- **꾸미기 → 전체 배경 이미지**에서 전체 런처 투명도(0~80%)를 조절합니다.
- **… → 중앙 문구 수정**에서 ‘나의 바로가기’ 제목과 중앙 안내 문구를 직접 작성합니다. 긴 칸 선택 목록은 제거했습니다.
- 미리보기를 확인한 뒤 적용합니다. 취소하면 등록 정보는 유지합니다. 이름·아이콘·메모를 편집해도 투명도 설정은 유지됩니다.
- 백업 파일명은 `DeckLauncher-backup-20261014-153045.zip`처럼 날짜·시간·초를 포함합니다. 같은 초에 저장하거나 같은 이름을 지정해도 `_2`, `_3`을 붙여 기존 파일을 보존합니다.
- 글꼴·테마 미리보기에도 사용자가 지정한 중앙 문구와 전체 투명도가 반영됩니다.

## 설치 및 업데이트

Windows 10/11 x64: `.NET 6 Desktop Runtime (x64)`가 필요합니다. `taskbar-launcher-v8.2.zip`을 풀고 `실행파일/DeckLauncher.exe`를 실행합니다. 기존 런처를 종료한 뒤 기존 폴더에 압축 내용을 덮어쓰면 됩니다. 패키지에 개인 Data 폴더는 들어 있지 않으므로 기존 `실행파일/Data`는 유지됩니다.

Linux x86_64: 패키지를 풀고 `bash install.sh --with-system-deps`를 실행합니다. 자세한 내용은 패키지의 README.md를 확인하세요.

macOS 14.4+ Apple Silicon/Intel: 패키지를 풀고 `install.command`를 실행하면 Mac에서 `.app`을 생성합니다. 최초 빌드에는 Python 3.10~3.15와 Apple Command Line Tools가 필요합니다. 완성된 앱은 Python 설치 없이 실행됩니다. Developer ID 서명·공증은 포함하지 않습니다. 자세한 내용은 패키지의 README.md를 확인하세요.

등록 정보는 OS별 기존 저장 위치를 유지합니다. 다른 운영체제에서 가져온 백업의 실행 대상은 해당 OS 앱으로 다시 연결해야 합니다.

## 검증 범위

Windows 201개, Linux 126개, macOS 144개 자동 검사를 통과했습니다. 여섯 디자인의 실제 투명도 렌더링, 함께/따로 전환, 저장·백업·복원, 일괄 적용 범위와 취소 보존을 확인했습니다. Windows의 실제 WPF 포인터 클릭·드래그 검사도 통과했습니다. Qt 설정창은 작은 화면에서 저장 버튼에 접근하도록 조절 영역을 스크롤할 수 있습니다.

Windows는 네이티브 WPF로, Linux/macOS는 Windows에서 Qt offscreen으로 확인했습니다. Linux/macOS의 실제 설치·Dock 동작은 실기 검증 전인 미리보기 버전입니다.
